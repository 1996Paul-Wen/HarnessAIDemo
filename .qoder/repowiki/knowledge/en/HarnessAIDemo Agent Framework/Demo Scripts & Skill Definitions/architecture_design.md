Each `demo_*.py` file is an independent executable entry point that bootstraps a Harness subsystem by inserting the repo root into `sys.path`, setting `HARNESS_LLM_BACKEND=mock`, importing the relevant `harness.*` components (LLM engine, agent types, tool registry, memory, skill loader), wiring them together, and running a short scripted or interactive flow. The `skills/` subdirectory holds declarative SKILL.md files with YAML frontmatter (`name`, `description`, `tags`, `version`) consumed by `harness.skill.loader.SkillLoader` via `demos/demo_skills.py`. There are no shared utilities between demos — each script is self-contained and demonstrates one feature surface: single-task agent (`demo_agent.py`), interactive chat with hybrid memory (`demo_chat.py`), session persistence (`demo_session.py`), MCP integration (`demo_mcp.py`), multi-agent orchestration (`demo_multi_agent.py`), and skill discovery/application (`demo_skills.py`).
