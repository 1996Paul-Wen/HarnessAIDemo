The module centers on `BaseAgent` in `base.py`, which implements the canonical agent loop: build context via `ContextManager`, call an injected `BaseLLM`, execute tool calls through `ToolRegistry`, append observations back into history, and stop when the LLM returns no tool calls or `max_iterations` is reached. `AgentTrace` records each iteration for debugging. Two concrete subclasses specialize the base: `ChatAgent` (in `chat.py`) configures a conversational system prompt with lower iteration limits and exposes `reset_conversation`/`get_conversation_history`; `TaskAgent` (in `task.py`) raises `max_iterations` and wraps `run` in a structured `execute_task` dict. `orchestrator.py` adds a supervisor pattern: `MultiAgentOrchestrator` maintains a registry of `BaseAgent` instances, uses an LLM-driven routing prompt (with keyword-based fallback) to pick a specialist, delegates execution, and supports running all agents in parallel via `run_with_all`. The package re-exports `BaseAgent`, `ChatAgent`, `TaskAgent`, and `MultiAgentOrchestrator` from `__init__.py`. Dependencies flow outward only to sibling packages (`harness.llm.engine`, `harness.tools.registry`, `harness.memory.*`, `harness.context.manager`); nothing inside this module imports other harness modules beyond those boundaries.
