The module defines a single abstract interface `BaseMemory` in `base.py` exposing `add`, `get_recent`, `search`, `clear`, `get_all`, plus a shared `MemoryItem` dataclass holding role/content/timestamp/metadata. Three concrete implementations extend this contract: `ShortTermMemory` (bounded FIFO deque, keyword overlap search), `LongTermMemory` (JSON-persisted list with TF-IDF retrieval via `math.log` IDF scoring), and `HybridMemory` (composition of the two, persisting only `user`/`assistant` roles to long-term and offering `get_relevant_context` that concatenates recent conversation with deduplicated relevant past memories). The package root `__init__.py` re-exports all public classes as the module's API surface. Dependency direction is strictly one-way: concrete implementations depend on `base`; `hybrid` depends on both `short_term` and `long_term`; no cross-imports between sibling implementations.
