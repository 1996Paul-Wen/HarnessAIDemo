Two sibling sub-packages with distinct responsibilities. `harness/session/manager.py` defines a `Session` dataclass (id, title, messages, metadata) and a `SessionManager` that persists each session as a JSON file under a configurable directory, tracks an active session id, and supports create/switch/list/delete/rename operations — acting like browser tabs for conversations. `harness/context/manager.py` defines a `ContextManager` that composes the full prompt for each LLM call by layering: (1) a base system prompt optionally augmented with tool-call instructions from a `ToolRegistry`, (2) relevant long-term context retrieved via a `BaseMemory`/`HybridMemory` instance, (3) short-term conversation history, and (4) the current user input; it also writes assistant responses back into memory. The two modules are independent of each other: sessions own raw message history while the context manager consumes any `list[Message]` plus external memory/tool registry to build prompts. Both packages expose their public classes through minimal `__init__.py` re-exports.
