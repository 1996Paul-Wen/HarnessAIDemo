Two-file module split into domain model and discovery logic. `base.py` defines the core types: `SkillMetadata` (dataclass holding name, description, tags, version) and `Skill` (holds metadata plus raw instructions, exposes `apply_to_prompt` to prepend skill instructions before user input, and `to_description` for listing). `loader.py` provides `SkillLoader`, which scans a configurable `skills_dir` (default `demos/skills`) for subdirectories containing a `SKILL.md` file, parses YAML frontmatter via regex (`--- ... ---`), falls back to extracting the first H1 heading when no name is present, and caches loaded skills in an internal `_skills` dict. The package `__init__.py` re-exports `Skill`, `SkillMetadata`, and `SkillLoader` as the public API. Dependency direction is one-way: loader depends on base; there are no external framework dependencies beyond stdlib `os`, `re`, `pathlib`, and `logging`.
